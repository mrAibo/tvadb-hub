# TVADB Hub distribution

This directory contains ready-to-run Windows build artifacts generated by GitHub Actions from the source tree.

## Windows

Expected files:

- `TVADB-Hub-0.1.0-windows-amd64.exe` — portable executable.
- `TVADB-Hub-0.1.0-windows-amd64-installer.exe` — per-user NSIS installer.
- `SHA256SUMS.txt` — SHA-256 checksums for both binaries.

These binaries are a release-candidate snapshot. Final v0.1.0 publication still requires the physical Google TV validation described in `docs/PHYSICAL_TV_VALIDATION.md`.
