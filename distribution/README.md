# DroidSphere distribution

This directory contains ready-to-run DroidSphere release-candidate packages
built from the repository source by GitHub Actions.

These committed packages are historical artifacts, not proof that current main
features are included. Earlier packages lack reliable per-artifact source
manifests; do not guess or backfill their source SHA. New builds publish
BUILD_PROVENANCE-<platform>.json with exact checkout SHA, dirty status, workflow
run, tool versions and SHA-256 digests.

## Latest Windows test candidate: 0.1.1 RC1 (2026-10-13)

The newest Windows binaries are retained separately under
[`windows/rc-0.1.1-faa9c28/`](windows/rc-0.1.1-faa9c28/):

- `DroidSphere-0.1.1-windows-amd64.exe` — portable Windows x64 program.
- `DroidSphere-0.1.1-windows-amd64-installer.exe` — Windows x64 NSIS installer.
- `BUILD_PROVENANCE-windows.json` — unmodified CI-generated source/build/hash metadata.
- `SHA256SUMS.txt` — checksums for the two executables and provenance JSON.

These exact files are from clean source commit
`faa9c28d6c5eb254c6471d17c8fa984bb8363f92`, GitHub Actions
[main CI run 38394525217](https://github.com/mrAibo/tvadb-hub/actions/runs/38394525217)
(success: all six jobs). Source version is `0.1.1`; RC1 is a test-candidate label
for this specific artifact set, not a new app version or a published GitHub Release.
Names inside the provenance JSON are unchanged from the original CI artifact.

The two older 0.1.1 Windows files directly in `windows/` are preserved as
historical packages; they do **not** contain this candidate's source features.
Do not confuse them with the nested `rc-0.1.1-faa9c28/` files.

This candidate has **not** yet passed physical Android/TV validation, full
Windows portable/installer interaction tests, or publication authorization.
See [`docs/PHYSICAL_DEVICE_VALIDATION.md`](../docs/PHYSICAL_DEVICE_VALIDATION.md)
and [release gate issue #19](https://github.com/mrAibo/tvadb-hub/issues/19).
Do not promote this candidate to a public release until that gate is satisfied.
## Latest macOS test candidate: 0.1.1 RC1 (2026-10-15)

Native universal `DroidSphere.app` for **Apple Silicon arm64 and Intel x86_64**
is available at [`macos/rc-0.1.1-c11c9eb/`](macos/rc-0.1.1-c11c9eb/):

- `DroidSphere-0.1.1-macos-universal.zip` — ad-hoc signed .app bundle
- `BUILD_PROVENANCE-macos.json` — macOS CI provenance with exact source SHA
- `SHA256SUMS.txt` — package and provenance checksums

The source is the clean `main` commit
`c11c9ebeb2b2047fc1b7ed96755a88238dc484bc`; the macOS
build verifies both `arm64` and `x86_64` architectures and checks the
ad-hoc signature. The older zip directly in `macos/` is preserved as a
historical artifact and must not be confused with this candidate.

**Not notarized by Apple; not a public Release or hardware-validated.**
On macOS, Gatekeeper may require Control-click → Open. Avoid disabling
system-wide security controls. Physical Android/TV compatibility is
still pending [release gate #19](https://github.com/mrAibo/tvadb-hub/issues/19).

## Windows

- `windows/DroidSphere-<version>-windows-amd64.exe` — portable executable.
- `windows/DroidSphere-<version>-windows-amd64-installer.exe` — per-user NSIS installer.

## Linux

- `linux/DroidSphere-<version>-linux-amd64.AppImage` — portable AppImage.
- `linux/DroidSphere-<version>-linux-amd64.deb` — Debian/Ubuntu package.

## macOS

- `macos/DroidSphere-<version>-macos-universal.zip` — universal
  `DroidSphere.app` bundle for Intel and Apple Silicon.

The repository macOS package is ad-hoc signed but not Apple-notarized yet.
Gatekeeper may therefore require Control-click → Open on first launch.

## Checksums

`SHA256SUMS.txt` contains SHA-256 checksums for every package in the
subdirectories above.

The packages are generated by `.github/workflows/distribution.yml`.
Do not edit compiled files manually.
